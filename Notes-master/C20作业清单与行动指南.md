## 五、一步一步行动指南

### ① 把 App 跑起来（迭代 #1 的硬前提）

两条路，任选其一：

- **路 A：真机（最省事，强烈推荐）**
  1. 安卓手机打开「设置 → 关于手机」连点 7 次「版本号」开启开发者模式；
  2. 「开发者选项」里打开 **USB 调试**；
  3. 数据线连电脑，手机弹窗选「允许 USB 调试」；
  4. Android Studio 设备列表出现你的手机 → 点绿色 ▶ 运行。
  （无需折腾虚拟化，比模拟器稳得多）

- **路 B：修好模拟器**
  上次卡在 `x86_64 emulation requires hardware acceleration`（AEHD 未安装）。解决方案按优先级：
  1. **管理员权限**打开 PowerShell，执行启用 Windows 虚拟机监控程序平台：
     `dism /online /enable-feature /featurename:HypervisorPlatform /all /norestart`
     重启电脑后模拟器会走 WHPX 后端；
  2. 或到 SDK Manager → SDK Tools 勾选安装 **Android Emulator hypervisor driver**（需 BIOS 里开启 VT-x）；
  3. 若 BIOS 未开虚拟化，需进 BIOS 开启 Intel VT-x / AMD-V。
  （下次继续时我可以先帮你检测 CPU 虚拟化支持状态，再决定走哪条）

### ② 「改一行代码立刻运行测试」（验收必做，10 分钟搞定）

推荐改应用名，效果最直观、讲解最好讲：

- 文件：`res/values-zh-rCN/strings.xml`（或 `res/values/strings.xml`）
- 把 `<string name="app_name">便签</string>` 改成你的名字，例如 `张三的便签`
- 重新点 ▶ 运行 → 桌面图标名字立刻变了 → 截图留证 ✅

备选（同样只改一两行）：
- 改主题色：`res/values/styles.xml` 或颜色资源，换列表标题栏颜色；
- 改列表空页面文案：`strings.xml` 里的 `note_empty` 相关条目。

### ③ 产出「整体结构分析」（对应老师第 1 问）

需要讲清（我可以下一步直接帮你生成这份文档）：
- **入口**：`AndroidManifest.xml` 里 launcher Activity → `NotesListActivity.java`（`net.micode.notes.ui` 包）；
- **四大模块**：`ui/`（界面）、`data/`（Notes/NotesDatabaseHelper 等 SQLite 数据层）、`model/`（WorkingNote 等数据模型）、`tool/` + `widget/`（工具与桌面小组件）；
- **第三方依赖**：几乎为零（纯 Android SDK，仅 legacy Apache HTTP），这正是「适合精读」的原因；
- **亮点/槽点**（老师第 4 问素材）：SQLite 单库多表 + 数据版本快照设计是亮点；GTask 同步模块耦合重、无单元测试、2011 年风格代码是槽点。
