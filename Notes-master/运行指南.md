## 一、已完成的改造清单（最小改动，未移动任何源码）

### 新增文件（Gradle 构建体系）
| 文件 | 作用 |
|---|---|
| `settings.gradle` | 声明模块与仓库（`include ':app'`）|
| `build.gradle` | 顶层，声明 AGP 9.4.1 |

```groovy
sourceSets {

        manifest.srcFile '../AndroidManifest.xml'
        java.srcDirs = ['../src']
        res.srcDirs   = ['../res']
    }
}
```

## 二、如何运行

1. 打开刚安装好的 **Android Studio**（首次启动会引导配置并下载 Android SDK，选默认路径即可）
2. **File → Open**，选择目录 `Notes-master`（就是含 `settings.gradle` 的那一层）
3. 等待右下角 **Gradle Sync** 完成（首次会下载 Gradle 9.6.0、AGP 及依赖，需要几分钟）
4. 顶部设备下拉框：**Device Manager → Create Device** 新建一个模拟器（推荐 API 34/35 的 x86_64 镜像）
5. 点绿色 ▶️ **Run 'app'**
6. 应用启动后，建议到系统设置里授予「存储 / 联系人」权限，避免个别功能异常

**关于下载源**：Wrapper 的 `distributionUrl` 已指向**腾讯云镜像**（`mirrors.cloud.tencent.com`），
国内下载 Gradle 更快。如果你在海外，可改回官方：
`https\://services.gradle.org/distributions/gradle-9.6.0-bin.zip`

## 五、关于 `R.id` 不能用于 `switch`（本次已修复）

编译时会报 **17 个「需要常量表达式」**，位置全部在 `switch` 的 `case R.id.xxx:` 上：

```
NoteEditActivity.java:511: 错误: 需要常量表达式
        case R.id.menu_new_note:
```

**原因**：AGP 8.0 起，出于增量构建性能考虑，资源 ID 不再生成 `static final` 常量
（可用 `javap` 验证，生成的 `R$id` 字段是 `public static int`，没有 `final`）。
Java 语言要求 `case` 标签必须是编译期常量，于是全部报错。

**为何不能靠配置绕过**：旧方案是在 `gradle.properties` 里写 `android.nonFinalResIds=false`，
但在 **AGP 9.4.1 中该选项已被标记 deprecated 且实际不再生效**（构建日志会提示
"deprecated … It will be removed in version 10.0"，而生成的 `R` 字段依然非 final）。
因此本次改为**在源码层适配**。

**本次改法**：把这 4 个 `switch` 共 17 个 case 改写成等价的 `if-else`，**逻辑完全不变**：

```java
// 改前
switch (item.getItemId()) {
    case R.id.menu_share:
        getWorkingText();
        break;
    default:
        break;
}

// 改后
final int itemId = item.getItemId();
if (itemId == R.id.menu_share) {
    getWorkingText();
}
```

涉及位置：
| 文件 | 方法 | case 数 |
|---|---|---|
| `ui/NoteEditActivity.java` | `onOptionsItemSelected` | 8 |
| `ui/NotesListActivity.java` | `onMenuItemClick`（多选菜单）| 2 |
| `ui/NotesListActivity.java` | `onClick` | 1 |
| `ui/NotesListActivity.java` | `onOptionsItemSelected` | 6 |

> 备选方案（若必须保持源码零改动）：把工具链降到 **AGP 8.13 + Gradle 8.13**，
> 此时 `android.nonFinalResIds=false` 才真正有效。代价是把 Android Studio 的
> *Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK*
> 手动改成本机 JDK 21（`D:\JDK21\jdk-21.0.10`），因为 Gradle 8.x 不支持 IDE 自带的 JBR 25。

## 六、可能遇到的报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `SDK location not found` | 还没配置 Android SDK | AS 首次启动向导里装 SDK，或在 `local.properties` 里写 `sdk.dir=...` |
| `Failed to find Platform SDK with path: platforms;android-34` | 缺 android-34 平台 | 点报错里的 *Install missing SDK package* 一键安装 |
| `Gradle distribution download failed` | 网络问题 | 已用腾讯云镜像；若仍失败，检查代理 |
| `找不到符号 org.apache.http.*` | `useLibrary` 未生效 | 确认 `app/build.gradle` 里有 `useLibrary 'org.apache.http.legacy'` |
| 打开后提示模块异常 / 显示为普通 Java 工程 | 根目录残留的 `.idea`、`Notes-master.iml` 是旧 ADT 配置 | 关掉 AS，删掉 `.idea` 和 `Notes-master.iml`，重新 Open |
| `Your project path contains non-ASCII characters` | 工程路径含中文目录名 | 已在 `gradle.properties` 加 `android.overridePathCheck=true`；彻底规避见第四节 |
| `错误: 需要常量表达式`（指向 `case R.id.xxx:`）| AGP 8+ 资源 ID 非编译期常量 | 已在源码层把 17 个 case 改为 `if-else`（见第五节）；**若把源码还原成 `switch` 会重新出现** |
| 警告 `android.overridePathCheck=true is experimental` | 该选项本身是实验性开关 | 可忽略；想静音可加 `android.sync.suppressAgpWarnings=UNSUPPORTED_PROJECT_OPTION_USE` |
| 警告 `android.nonFinalResIds ... is deprecated` | 只在你手动加回该旧选项时出现 | AGP 9 已不再支持它，删掉该行即可 |
| `Unsupported Java version` | Gradle JDK 太新或太旧 | Settings → Build Tools → Gradle → *Gradle JDK* 选 `jbr-25`（或 21） |
